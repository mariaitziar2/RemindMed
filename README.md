# RemindMed
Este proyecto detecta si una caja de medicamentos ha sido abierta usando un sensor conectado a un Arduino. La información se envía por Bluetooth a una aplicación móvil desarrollada con MIT App Inventor. Es útil para recordar la toma de medicamentos.
Incluye:
- Código Arduino para leer el sensor y enviar datos por Bluetooth.
- Aplicación móvil para recibir los datos y mostrar notificaciones.
